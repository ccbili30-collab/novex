# Novex 3.0.6-beta.109 预览版发布

**日期**：2026-10-02
**通道**：preview

> ⚠️ **请勿更新**：本版是清洗工程收尾期的功能预览，只应安装在与我们协作测试的设备上。普通用户请停留在当前正式版（3.0.5），等待公告推荐再升级。

## 这一版做了什么

**官方供应商通道开箱即用**——添加供应商改为三选一引导，各带品牌标识：

- **智谱**：选卡后只需填 API Key，即连官方接口——模型目录（GLM-5.3 系）内置，思考开关按智谱规格接线，取钥链接直达
- **深度求索**：同样只填 API Key，模型列表自动拉取，失败时内置兜底
- **自定义**：手动填地址与密钥，流程如旧

同步修复：兼容中转上 o 系 / gpt-5 模型的参数键选择（此前会整单报错）、智谱思考关闭档的语义（按官方指引以最浅档模拟关闭）。

## 升级须知

- 数据无损，直接安装覆盖即可
- 已配置的供应商不受影响；想让智谱开箱即用，可在设置里重新走一遍添加流程体验新版引导
