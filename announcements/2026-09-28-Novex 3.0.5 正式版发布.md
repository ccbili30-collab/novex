# Novex 3.0.5 正式版发布

**日期**：2026-09-28
**通道**：稳定版（Stable）

Novex 3.0.5 正式版现已发布。本版本为一次核心架构升级，涵盖自 3.0.4 以来经预览通道逐批验证的全部变更，聚焦记忆体系、分发体系与设置架构三个方向。

## 新增

- **模块标签系统**：卡片模块支持「去向」（默认携带 / 每轮注入 / 风格 / 待命）与「时间性」（常量 / 快照）标签，由标签决定开局携带与压缩后的重注入策略；存量卡片无需迁移，行为保持不变。
- **开局资料包**：挂卡对话激活时自动生成居中资料包，以用户消息形式注入并驱动 AI 直接开场（世界卡进入叙述模式，角色卡以角色身份开场）。
- **随身笔记与世界快照**：长对话按上下文水位自动整理记忆笔记（后台执行，不占用对话节奏）；上下文压缩时生成世界状态快照，常量设定自动重注入，缓解长对话的记忆漂移。
- **存档系统**：对话内 `/save`、`/saves`、`/load` 命令组；上下文压缩时自动存档，可随时回档。
- **双源更新**：应用内更新检查默认 Gitee 源（国内直连），可切换 GitHub 源（海外）；预览版与正式版为独立安装通道，互不干扰。
- **公告系统**：公告随更新源获取；有新公告时打开应用即提醒，关闭视为已读。

## 改进

- **卡片采用界面重构**：原「卡片采用与管理」合并页拆分为三个独立页面——回答身份（单选，角色·扮演与世界·GM 叙述分组呈现）、背景资料（多选，含模块携带控制）、管理内容（多选，仅授予编辑权限）。
- **指令优先级**：自定义对话提示词修复后位于系统指令最高优先级，长对话中不再被稀释。
- **聊天界面**：消息流式渲染、助手消息操作行与工具执行过程展示全面优化。
- **提示词工程**：系统提示词、卡片契约与记忆整理提示词按结构化规范重写，指令遵循度提升。

## 变更与修复

- 移除已停止服务的 opencode 免费模型入口。
- 修复自定义对话提示词不生效的问题。
- 修复纯创作会话在上下文压缩后生成无效世界快照的问题。
- 其他稳定性修复。

## 升级方式

设置 → 关于 → 检查更新，或前往仓库「发行版」页面下载安装包（约 35MB）。旧版本数据与卡片无需迁移，升级后原有对话直接延续。
