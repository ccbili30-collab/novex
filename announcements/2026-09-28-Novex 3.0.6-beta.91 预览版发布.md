# Novex 3.0.6-beta.91 预览版发布

**日期**：2026-09-28
**通道**：preview

上一版公告面板改版后的第一批体验修复，全部来自预览用户的实测反馈。

## 改进

- **阅读视图全局化**：滚动 / 翻页正式成为纯渲染模式——切换不改动卡片数据、不产生修订，所有卡片统一生效，默认翻页。
- **存储可见性**：存储管理页新增「卡片内容」与「卡片修订历史」两行，数据目录的构成从此可自查。

## 变更与修复

- 编辑菜单「默认连续阅读 / 默认模块翻页」更名为「滚动模式 / 翻页模式」，且设置即时生效。
- 修复导入卡的简介显示为原始 JSON 的问题：嵌套的资料 JSON 现在会自动解包出真正的简介。
- 图片内存占用封顶：图片缓存固定 128MB 上限，全屏看图不再累积独立缓存，长时间使用的内存占用显著下降。

## 升级方式

设置 → 关于 → 检查更新。本条公告仅下发给预览通道。
