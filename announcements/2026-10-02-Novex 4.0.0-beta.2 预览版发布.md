# Novex 4.0.0-beta.2 预览版发布

**日期**：2026-10-02
**通道**：preview

Novex 进入 4.0 时代——模型接入、数据层、运行时与界面骨架完成整体重构。

## 这一版有什么

- **官方供应商开箱即用**：添加模型供应商改为三选一引导——选「智谱」或「深度求索」，填入 API Key 即可开始使用（接口地址、模型目录、思考开关全部预置，取钥链接直达）；「自定义」走手动配置
- **升级平顺**：与旧版同签名，直接覆盖安装；本地数据（对话、卡片、世界）无损保留
- 底层完成重构并完成第三方许可合规（应用内随附开源组件声明），为后续更快的功能迭代铺路

## 适合谁更新

预览通道用户推荐升级体验。正式版用户可继续停留在 3.0.5，等 4.0 正式版公告。

> 更新方式：设置 → 关于 → 检查更新，或从发布页直接下载安装包覆盖安装。
